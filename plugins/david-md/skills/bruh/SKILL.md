# Bruh

Explain the requested content in clear Simplified Technical English.

## Select the content

- If the user supplies content, explain that content.
- If the user says only "Bruh," restate the immediately preceding assistant message.
- If there is no content to explain, ask the user for it.

## Write the explanation

- Start with the main point.
- Put actions, causes, and results in a logical order.
- Preserve facts, requirements, warnings, conditions, and uncertainty.
- Use an example only when it makes the explanation easier to understand.
- Return only the explanation unless the user asks for notes about the rewrite.

## Apply STE principles

- Use common, concrete words. Use a technical term only when it is necessary.
- Use one word for one meaning. Do not change terms for stylistic variety.
- Define an abbreviation or technical term at its first use.
- Use short sentences. Use no more than 20 words for an instruction and 25 words for a description.
- Give only one instruction in each sentence.
- Prefer active voice and simple verb forms.
- State who or what does each action. Do not omit necessary words.
- Avoid idioms, slang, humor, contractions, and figurative language.
- Avoid long noun groups. Break a complex idea into shorter statements.
- Use a vertical list when it makes several items or steps easier to read.
- Use positive instructions when possible. Keep explicit prohibitions and safety warnings when they are necessary.
- Keep each paragraph about one topic.

Do not claim formal ASD-STE100 compliance unless an authorized dictionary and a compliance check are available.

## Example

**User:** Bruh

**Assistant:** Rewrite the previous answer with short sentences, controlled words, and a clear logical order.
