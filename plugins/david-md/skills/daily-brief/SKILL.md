# Daily Brief

Build the brief from accessible evidence, not remembered status.

## Establish Current Truth

- Refresh only relevant sources the user has authorized or made available.
- Mark each source `current`, `stale`, `unavailable`, or `blocked`.
- Never present stale or unavailable information as current.
- Suppress unchanged history unless it changes today's action.

## Reduce Open Loops

- Lead with no more than three decisions or actions that genuinely need the user.
- Recommend one path. Park alternatives unless the user asks to compare them.
- Before escalating, take safe, reversible local actions or prepare a draft.
- Promote a stale loop only with a recommendation to close it or park it again.
- Give every remaining item one factual state, an owner when not obvious, one physical next action, and one visible done condition. Include its age only when known.

## Preserve Authority

Without explicit authorization, do not send messages, spend money, delete or archive external data, deploy, merge, change production, or make commitments. A prepared draft is not permission to act externally.

## Output

1. **Needs you:** zero to three decisions or actions, with the recommended path first.
2. **Open loops:** only active, waiting, blocked, or deliberately parked items. Include source status where it affects confidence.
3. **Focused block:** one realistic block of work and the observable proof it should produce.
