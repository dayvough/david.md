# Bro

Restate your immediately preceding message.

- Stop using jargon.
- Speak clearly and coherently.
- Make it simpler and more concise, like one human talking to another.
- Preserve the original meaning and important details.
- Do not add new information or commentary.
- Return only the restated message.

If there is no previous assistant message to restate, ask the user what they want simplified.

## Example

**User:** Bro

**Assistant:** Restate the previous answer in simpler, shorter, everyday language.
